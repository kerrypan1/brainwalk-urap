# BRAINWALK URAP

This repository contains research code and experiments from three undergraduate URAP researchers, Kerry, Qixing, and Joseph, working on the BRAINWALK project.

Our goal is to use walking videos from patients with multiple sclerosis (MS) to predict clinician-assessed gait impairment, primarily through the Functional Gait Assessment (FGA) score.

The repository is organized by researcher:

```text
/
├── kerry/
├── qixing/
└── joseph/
```

Each folder contains the code, experiments, and results for that researcher's approach.
